# WondoVerse — initial scaffold

This repository now contains a minimal React + Vite + TypeScript + React Three Fiber scaffold implementing a small playable prototype:

- A low-poly flat meadow
- A simple Wondo-like player object
- Keyboard movement and jump
- A floating Wonder Star collectible (increments counter)
- A basic math modal activity and a tiny AI teaching simulation
- Local progress saved to localStorage

How to run:

1. Install dependencies

   npm install

2. Run development server

   npm run dev

3. Build for production

   npm run build

Notes:
- This is an initial playable prototype. Next steps: polish visuals, add animations, touch joystick UI, accessibility improvements, quest engine, and tests.
